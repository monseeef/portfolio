A premium personal portfolio for **Monsif El Ouarat**, built to present full-stack development, React Native, and UI/UX skills with a polished recruiter-friendly experience.

The site focuses on clean visual hierarchy, smooth motion, responsive layouts, and a modern slate plus emerald design system.

## Overview

This portfolio highlights:

- A modern hero section with animated role text
- Technical skills across frontend, backend, mobile, and design
- Featured project cards with tech stacks and action links
- Professional experience timeline
- Contact section with copy-to-clipboard email support
- SEO-ready metadata and social preview placeholders

## Tech Stack

- **React** for component-based UI
- **Vite** for fast development and production builds
- **Tailwind CSS** with `@tailwindcss/vite`
- **Framer Motion** for lightweight interaction and reveal animations
- **Lucide React** for clean interface icons

## Features

- Fully responsive layout for mobile, tablet, and desktop
- Fixed glassmorphism navbar with active section highlighting
- Smooth scrolling and top scroll progress indicator
- Mouse-follow radial glow effect
- Animated gradient hero heading
- Floating hero particles
- Magnetic hover effect for primary buttons and links
- Dark glassmorphism cards with emerald glow accents
- Accessible semantic sections and focus states
- SEO and Open Graph metadata
- Production-ready `.gitignore`

## Installation

Clone the repository and install dependencies:

```bash
git clone <repository-url>
cd portfolio
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal, typically:

```bash
http://127.0.0.1:5173
```

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |

## Deployment

This project can be deployed on platforms such as **Vercel**, **Netlify**, or **GitHub Pages**.

Recommended build settings:

```bash
Build command: npm run build
Output directory: dist
```

For Vercel or Netlify, import the repository, keep the default Vite settings, and deploy.
